# Buscador de CEP 🔍

Este é um projeto de busca de CEP desenvolvido em Java, onde o usuário pode informar um CEP e o programa retorna o endereço correspondente diretamente no terminal.

## Tecnologias Utilizadas ⚒️🖥️

- **Java**: Linguagem utilizada para o desenvolvimento do sistema.
- **API**: ViaCEP (API pública para consulta de CEPs no Brasil)

## Funcionalidades 🚀

- O programa recebe um CEP informado pelo usuário.
- Realiza a consulta na API ViaCEP e retorna o endereço correspondente.
- Exibe o logradouro, bairro, cidade, estado e unidade federativa (UF).

## Como Usar ⁉️
1. Clone o repositório:

     git clone https://github.com/antoniotiburtino/buscador-cep.git

2. Navegue até a página do projeto:

    cd buscador-cep

3. Compile o código Java:
   
   javac BuscaCEP.java

4. Execute o programa:

   java BuscaCEP

5. O programa solicitará que você insira um CEP e, em seguida, exibirá o endereço correspondente no terminal

## Como Funciona ⁉️
O programa utiliza a API pública ViaCEP para realizar a consulta do CEP informado. Ele faz uma requisição HTTP à API e exibe os dados retornados no terminal, como o logradouro, bairro, cidade, estado e UF.
